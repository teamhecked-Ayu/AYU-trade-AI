# Database migrations

AYUAI uses Alembic to version database schema changes.

## Local setup

Install dependencies:

    pip install -r requirements.txt

Apply all migrations:

    alembic upgrade head

## Creating migrations

After changing SQLAlchemy models:

    alembic revision --autogenerate -m "describe schema change"

Review generated migrations before applying them. Never run autogenerated migrations blindly against production data.

## Production rules

- Take a verified backup before destructive migrations.
- Run migrations as a deployment step, not from application request handlers.
- Test upgrades on a staging database first.
- Store the database URL in deployment secrets, not in Git.
